# 🌦️ Weather Application using Python

A simple Weather Application built using Python, Tkinter GUI, and OpenWeatherMap API.  
This application allows users to enter a city name and get real-time weather information such as temperature, humidity, wind speed, and weather condition.

---

## 📌 Features

- Simple and user-friendly GUI
- Get real-time weather updates
- Displays:
  - Temperature
  - Humidity
  - Wind Speed
  - Weather Condition
- Error handling for invalid city names
- Uses OpenWeatherMap API

---

## 🛠️ Technologies Used

- Python
- Tkinter
- Requests Library
- OpenWeatherMap API
